# QA Automation Classwork

This repository contains my classwork, exercises, and assignments from the **QA Automation** course.

It serves as a central place to keep my work organized, track my progress over time, and practice working with Git in a real-world workflow.

## Purpose

- Store class exercises and homework assignments
- Practice test automation concepts and tools
- Keep a versioned history of my learning progress
- Practice team-style Git workflows (branches, commits, pull requests)

## Topics Covered

The content grows as the course progresses. Topics may include:

- Software testing fundamentals and QA methodologies
- Test planning and test case design
- Automated UI testing
- API testing
- Working with test frameworks and assertions
- Test reporting and best practices
- Version control with Git

## Getting Started

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd <repository-name>
   ```
2. Switch to the relevant branch:
   ```bash
   git checkout <branch-name>
   ```
3. Follow any instructions found inside each lesson or assignment folder (setup steps, dependencies, how to run the tests).

## Branching and Workflow

- `main` holds the stable, reviewed work.
- New work is done on separate branches and merged when complete.
- Commit messages should be short and descriptive.
